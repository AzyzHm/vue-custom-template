# Security Policy

## Supported Versions

As a template repository, only the latest state of `main` is supported. There are no maintained
release branches.

| Version | Supported |
| ------- | --------- |
| `main`  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public GitHub issue.**

Instead, report it privately by emailing **elhammemi001@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (proof-of-concept code is welcome)
- Any suggested mitigation, if you have one

You should expect an initial response within **5 business days**. We'll work with you to understand
and validate the issue, and to agree on a disclosure timeline once a fix is available.

## Scope

This template ships example client-side code and a mocked API layer for demonstration purposes only.
When using it as the base for a real application, review environment variable handling, API
authentication, and CORS configuration for your own deployment, these are intentionally left generic here.
